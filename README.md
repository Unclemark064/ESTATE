# Keyhold – Real Estate Marketplace Demo

A modern, responsive front-end demo for a Nigerian real estate marketplace platform with zero dependencies, vanilla JavaScript, and refined glassmorphic styling.

![Keyhold Preview](images/prop-1.jpg)

## 🌟 Features

- **Geographic Coverage**: 12 curated properties spanning Lagos, Abuja, Port Harcourt, and Enugu.
- **Glassmorphic UI**: Frosted glass sticky navigation bar, backdrop blurs, refined typography, and subtle micro-interactions.
- **Dynamic Hero Section**:
  - Rotating Nigerian city cycler.
  - Instant search & property type filter bar.
  - Floating highlighted stat cards and live featured property preview.
- **Inspection Booking**: Interactive calendar slot selector with automatic collision detection for taken dates/times.
- **Listing Publisher**: Modal form to publish new properties with client-side image compression and live photo preview.
- **My Visits Dashboard**: Manage inspection appointments (confirm, decline, or cancel requests saved to `localStorage`).
- **Marketing & Social Proof**:
  - Key metrics & highlights strip.
  - "Meet our agents" consultant showcase.
  - 3-step "How It Works" flow.
  - Testimonial carousel with star ratings and dot pagination.
  - Accessible FAQ accordion.
  - Real estate market insights blog section.
  - Newsletter subscription with instant toast feedback.
  - 4-column footer with quick navigation links.

## 🚀 Getting Started

No build tools, bundlers, or package installations are required!

1. Clone the repository:
   ```bash
   git clone https://github.com/Unclemark064/ESTATE.git
   ```
2. Open `index.html` (or `Keyhold – real estate demo.html`) directly in any modern web browser.
